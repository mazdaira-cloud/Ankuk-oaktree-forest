# 🌳 안국 700 떡갈나무: 디지털 사회적 조각 (PWA Web App)
> **요셉 보이스(Joseph Beuys)의 《7000그루의 떡갈나무》 철학을 차용한 시민 참여형 플로깅 & 지자체 행정 제안 Progressive Web App**

본 프로젝트는 북촌, 계동길, 인사동, 익선동 등 안국역 일대의 무단 투기 사각지대를 시민의 직접 정화(플로깅)로 치유하고, 수집된 GIS 공간 분석 데이터를 바탕으로 지자체(종로구청/환경부)에 공공 쓰레기통 확충을 제안하는 **현대적인 Progressive Web App(PWA)**입니다.

---

## 🎨 철학적 배경: 사회적 조각 (Social Sculpture)

> *"모든 인간은 예술가이며, 사회를 조각할 수 있다." — Joseph Beuys*

독일의 개념미술가 요셉 보이스는 1982년 카셀 도큐멘타 7에서 7000개의 거친 현무암 돌기둥을 쌓아두고, 시민들이 떡갈나무를 한 그루씩 심을 때마다 돌기둥을 하나씩 옮겨 나무 곁에 세우는 《7000그루의 떡갈나무(7000 Eichen)》 프로젝트를 진행했습니다.

본 Web App은 이 철학을 디지털로 계승하여:
1. 무단 투기 취약 구역을 **Lv.0 도토리와 현무암 돌기둥**으로 지정합니다.
2. 시민이 현장에서 쓰레기를 줍고 사진으로 인증할 때마다 **씨앗 → 새싹 → 본잎 → 어린 나무 → 큰 나무 → 고령 나무 → 세계수(Lv.7)**로 거점이 실시간 진화합니다.
3. 정화 활동을 통해 거리의 질서를 시민 연대의 힘으로 직접 '조각'합니다.

## 📱 Web App & PWA 핵심 기능

### 1. 📲 Progressive Web App (PWA) 규격 완비
* **홈 화면 설치**: 데스크톱(Chrome/Edge) 및 모바일(iOS/Android) 브라우저에서 `[📲 앱 설치]` 버튼으로 네이티브 앱처럼 설치 및 독립 창(Standalone) 실행 지원.
* **오프라인 캐싱 (`sw.js`)**: Service Worker를 통해 앱 쉘, Leaflet 맵 타일, 폰트 및 에셋을 로컬에 캐시하여 네트워크가 불안정한 환경에서도 즉각 구동.
* **앱 매니페스트 (`manifest.webmanifest`)**: 고해상도 벡터/래스터 앱 아이콘, 테마 컬러(`#047857`), 바로가기 숏컷(플로깅, 제보, 행정리포트, 에코쉼터) 탑재.

### 2. 📱 모바일-퍼스트 반응형 UI/UX (App Shell)
* **모바일 바텀 내비게이션 바**: 한 손 조작에 최적화된 하단 5대 탭 (`📍 숲 지도`, `🏃 플로깅`, `📸 제보`, `🌿 에코쉼터`, `🏛️ 행정제안`) 제공.
* **다크 / 라이트 모드**: 헤더 우측 `🌙 / ☀️` 토글을 통해 야간 플로깅 시 눈의 피로를 최소화하는 테마 지원.
* **실시간 GPS 인디케이터**: 사용자 위치를 지도상 펄스(Pulsing) 링으로 표시.

### 3. 🏃 실시간 플로깅 운동 트래커 (Live HUD)
* **실시간 운동 기록**: 상단 플로팅 HUD를 통해 경과 시간(`MM:SS`), 보행 이동 거리(`km`), 소모 칼로리(`kcal`), 수거 쓰레기 개수를 실시간 측정.
* **지도상 실시간 이동 궤적(Polyline)**: 보행 경로를 에메랄드빛 실시간 선으로 지도에 드로잉.
* **일시정지 / 재개 / 수거 카운트**: 플로깅 중 간편 조작 및 마일리지 보너스 적립.

### 4. 📜 700 떡갈나무 수호목 완주 & 성장 디지털 인증서 발급기
* **HTML5 Canvas 실시간 렌더링**: 플로깅 완주 시 발급 번호, 완주 거리/시간/칼로리, 요셉 보이스 명언, 안국 사회적 조각인 직인이 날인된 고화질 디지털 인증서 생성.
* **원클릭 이미지 저장 & SNS 공유 (`navigator.share`)**: 인스타그램 스토리 및 모바일 SNS로 즉시 공유 가능.

### 5. 🗺️ 지도 인터페이스 및 50m 버퍼 공간 분석
* **중심 좌표**: 서울 안국역 일대 (`37.5765, 126.9855`, Zoom: 16)
* **[레이어 1] 8단계 떡갈나무 성장 거점**: 경험치(`exp`)에 따른 8단계 레벨업 및 Lv.7(세계수) 황금빛 방사형 아우라(Glow) 방출.
* **[레이어 2] 공공 쓰레기통 및 50m 유효 버퍼 (OA-15069)**: 종로구 공공 쓰레기통 50m 원형 버퍼 시각화.
* **[사각지대 붉은 점멸 하이라이트]**: 쓰레기통 50m 버퍼 바깥의 취약 거점은 붉은 점멸 경고 링(Pulsing Red)과 ⚠️ 배지로 강조.
* **[레이어 3] 추천 플로깅 순회 노선**: 안국역 출구 → 주요 사각지대 → 공공 쓰레기통 연결 보행 라인.

### 6. 🏛️ 지자체 제안용 행정 인사이트 대시보드
* **신규 쓰레기통 설치 권고 Top 3 구역**: 50m 버퍼 밖 최대 투기 지역 정밀 좌표 및 이격 거리 자동 산출.
* **📁 GeoJSON 표준 공간데이터 다운로드**: 원클릭 GIS 파일 내보내기.
* **📋 종로구청 건의 공문 전문 원클릭 복사**: 전자민원/안전신문고 서식 자동 생성.

### 7. 🌰 도토리 에코 지갑 & 모바일 바코드
* 획득한 도토리 마일리지(Exp)로 안국역 일대 제로웨이스트 샵 및 카페 텀블러 할인 쿠폰 바코드 즉시 제시 가능.

## 🚀 실행 가이드

### 1. 브라우저에서 바로 실행 (무설치)
별도의 Node.js 설치나 빌드 없이, `index.html` 파일을 더블 클릭하거나 브라우저에서 열면 모든 기능이 즉시 작동합니다:

```powershell
Start-Process "c:\Users\User\.gemini\antigravity\scratch\anguk-clean-route\index.html"
```

### 2. 로컬 웹 서버로 실행 (PWA Service Worker 테스트)
```bash
npm run dev
# 또는
npx -y serve . -l 3000
```
